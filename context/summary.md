# Project Naming Summary

## Project Concept

A combination of AI-related technologies that allows LLMs to interact through a context-generation CLI in realtime to perform better.

## Technologies Being Combined

| Technology | Purpose |
| -- | -- |
| [worktrunk](https://github.com/max-sixty/worktrunk) | Git worktree management for running multiple AI agents in parallel |
| [memvid](https://github.com/memvid/memvid) | Portable single-file memory system for AI agents (persistent long-term memory) |
| [autocoder](https://github.com/leonvanzyl/autocoder) | Autonomous AI coding agent using Claude Agent SDK for multi-session development |
| [gibram](https://github.com/gibram-io/gibram) | In-memory knowledge graph for RAG (retrieval-augmented generation) |
| [adversarial-spec](https://github.com/zscole/adversarial-spec) | Multi-model specification refinement through structured debate |
| [Anthropic harness patterns](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents) | Techniques for long-running agents: initializer agents, progress tracking, incremental work |
